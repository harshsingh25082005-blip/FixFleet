# FixFleet 🚀

**Team FixFleet**

FixFleet is a platform that connects customers with reliable local home-service professionals such as **plumbers, electricians, carpenters, cleaners, painters, and appliance technicians**.

## 🎯 What FixFleet Does

* 🔍 Find nearby service professionals
* 👤 View profiles, skills, experience, ratings, and charges
* 📅 Book services based on availability
* 💳 Make secure payments
* 🔔 Receive booking and service updates
* ⭐ Rate and review professionals
* 👷 Service providers can manage profiles, availability, and bookings
* 🛡️ Admins can verify providers and handle complaints

## 🔄 How It Works

**Customer → Search Service → Choose Provider → Book → Pay → Service → Review**

## 🌟 Goal

FixFleet aims to make finding local home-service professionals **faster, safer, and more transparent**, while helping skilled workers find and manage more service opportunities.
